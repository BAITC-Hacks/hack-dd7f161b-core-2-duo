## Методика

Все сотрудники обходятся по ID; overlay пуст, история включена, цели наследуются из профиля. Датой расчёта служит as_of_date набора, а не календарная дата запуска. Рекомендации - все показанные top-3, каждая применяется отдельно к исходному состоянию: карточки являются альтернативами.

Допуск независимо проверяет обязательность, текущую роль/грейд, AND-prerequisites, завершения и сессии. Для continue нужен актуальный in_progress; согласно §9.2 аудитория, prerequisites и прошедшая сессия не проверяются задним числом. Исключение повторяемости: EV_036. Snooze отсутствует в исходном overlay.

Начальные навыки, цель, готовность и формула gain вычисляются отдельно от функций движка. Проверяется `delta=max(0,min(gain,max_level-before,5-before))`. Если исходный навык уже выше cap события, он сохраняется: корректная верхняя граница after - max(before, cap), при шкале ≤5. Таких исходных эффектов: 15/702 (2.14%).

Полезность означает положительное сокращение целевого разрыва либо допустимую цепочку, в которой первый шаг закрывает prerequisite следующего события и итог уменьшает целевой разрыв. Это операционный критерий, а не измеренная польза сотруднику. Категории считаются по структурным facts, не по тексту LLM. HISTORY_INSUFFICIENT считается честным контекстом истории.

Для каждого главного шага сравниваются готовность simulate и полного build_snapshot после completion-overlay с допуском 1e-9 процентного пункта; отдельно сравниваются все навыки. Для каждого неповторяемого рекомендованного события проверяются повторная выдача и simulate([event,event]).

## Синтетические сравнения

Baseline выбирает самый низкий текущий навык среди открытых целевых разрывов (равенство разрешается по skill_id), затем первое допустимое событие в порядке events.json с номинальным gain>0 для этого навыка. Caps, критичность и история не ранжируются; если события нет, baseline останавливается. Continue допускается по тем же правилам. Критерии заданы в manifest.json каждого случая; ожидаемые ID не используются как оракул.

| Случай и критерий | Baseline | Движок | Результат критерия |
|---|---|---|---|
| Повторные неявки на очный формат: Выбран допустимый шаг с положительным сокращением целевого разрыва, формат которого отличается от формата трёх недавних неявок; сравниваемые новые курсы имеют одинаковый прирост и нагрузку. | `EV_OFFLINE_NEW` (start) | `EV_ONLINE_NEW` (start) | только движок выполняет критерий |
| Критический разрыв при более низком некритическом навыке: Главный шаг должен уменьшить сумму открытых критических разрывов минимум на один уровень. | `EV_OPTIONAL` (start) | `EV_CRITICAL` (start) | только движок выполняет критерий |
| Потолок первого курса уже достигнут: Выбранное действие должно фактически уменьшить открытый целевой разрыв минимум на один уровень после применения gain и max_level. | `EV_CAPPED` (start) | `EV_GROWTH` (start) | только движок выполняет критерий |
| Подготовка открывает недоступный целевой курс: Выбран доступный шаг, после которого выполняются предпосылки целевого курса; этот курс затем фактически уменьшает целевой разрыв. Начальный целевой курс должен быть заблокирован предпосылками. | нет шага | `EV_PREPARE` (start) | только движок выполняет критерий |
| Завершение уже начатого курса: Выбрано продолжение начатого полезного курса с оставшейся длительностью меньше полной длительности сопоставимого нового курса. | `EV_NEW` (start) | `EV_ACTIVE` (continue) | только движок выполняет критерий |

Критерий выполнен движком: 6/6 (100.00%); baseline: 1/6 (16.67%). Только движок: 5/6 (83.33%); оба: 1/6 (16.67%). Это результаты специально сконструированных случаев, не ML accuracy и не оценка скрытых профилей жюри.

- **Повторные неявки на очный формат.** У двух новых курсов одинаковы навык, прирост, потолок, длительность и дата сессии. Первый курс очный, второй дистанционный. За последние 30 дней наблюдаются три неявки на другие очные курсы. Критерий заранее предпочитает альтернативный формат при равном полезном эффекте. Прямое сокращение разрывов: движок 1, baseline 1 уровней навыков. Ограничение: Выбор другого формата - заранее заявленная эвристика этого примера, а не доказательство будущей явки или предпочтений сотрудника. Три записи истории искусственно сконструированы; эмпирической метки лучшего формата нет.
- **Критический разрыв при более низком некритическом навыке.** Некритический навык имеет уровень 0 при требовании 1, критический - уровень 1 при требовании 2. Оба курса дают один полезный уровень за одинаковое время. Критерий заранее отдаёт приоритет уменьшению критического разрыва. Прямое сокращение разрывов: движок 1, baseline 1 уровней навыков. Ограничение: Приоритет критических требований - заданная политика, а не измеренный эффект на продвижение сотрудника.
- **Потолок первого курса уже достигнут.** Единственный целевой навык имеет уровень 1 при требовании 3. Первый допустимый курс обещает номинальный gain 1, но ограничен max_level 1; второй имеет max_level 3 и способен дать полезный прирост. Критерий - положительное фактическое уменьшение целевого разрыва. Прямое сокращение разрывов: движок 1, baseline 0 уровней навыков. Ограничение: Наивное правило специально использует заявленный gain; оно не фильтрует активности по фактическому приросту, поскольку тогда перестало бы быть заявленным однофакторным правилом.
- **Подготовка открывает недоступный целевой курс.** Целевой курс развивает единственный критический целевой навык, но требует уровень 1 отдельного подготовительного навыка. Сейчас оба навыка на нуле. Подготовительный курс доступен и открывает целевой курс за один шаг; подготовительный навык не входит в целевые требования. Прямое сокращение разрывов: движок 0, baseline 0 уровней навыков. Ограничение: Критерий проверяет достижимую цепочку из двух self-paced активностей; он не доказывает оптимальность маршрутов произвольной длины.
- **Завершение уже начатого курса.** Два курса развивают один целевой навык на один уровень. Новый курс стоит первым в каталоге и занимает 8 часов. Второй курс уже выполнен на 75%, поэтому для того же эффекта осталось 2 часа. Критерий заранее предпочитает полезное продолжение с меньшей оставшейся нагрузкой. Прямое сокращение разрывов: движок 1, baseline 1 уровней навыков. Ограничение: Линейная оценка оставшихся часов взята из текущей модели продукта и не является измерением реальной длительности завершения.
- **Пустая история: нейтральный контроль.** Один сотрудник, один открытый целевой разрыв и один полезный допустимый курс. История содержит только заголовок CSV. Выбор обоих методов должен совпасть; оценка истории движка должна оставаться нейтральной и сообщать о недостатке наблюдений. Прямое сокращение разрывов: движок 1, baseline 1 уровней навыков. Ограничение: Это контроль отсутствия ложного исторического сигнала, а не случай превосходства одного метода. Наивное правило не генерирует обоснование, поэтому отдельная проверка факта недостаточной истории относится только к движку.

## Ограничения

В наборе нет размеченных лучших рекомендаций и результатов вмешательства. Не оценивались рост завершений, удержание, повышение, семантическая истинность всех фактов/объяснений, авторизация, UI и производительность сети. Диагностика дублированного overlay проверяет ядро напрямую и не означает, что UI отправляет такие дубли; проверка EV_036 ограничена сессиями исходных рекомендаций. Планировщик ограничен глубиной и шириной поиска; отсутствие найденного пути не доказывает невозможность развития. Метрики относятся к указанным хешам кода и данных; после слияния исправлений отчёт нужно пересоздать. Сравнение касается только описанных synthetic fixtures и не характеризует другие команды.
